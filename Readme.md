## Prerequisites

- **Java 11** installed and JAVA_HOME set.

- **Maven** (3.6+) installed and on PATH.

- Internet access for LambdaTest runs (if isLambdaTest=true).
  (Optional) Browser drivers if you run locally without    WebDriverManager (or ensure WebDriverManager is configured).

- **LambdaTest** account (username / accessKey) if running on LambdaTest.
## Features
- Cross-browser support (Chrome, Firefox)
- Local & LambdaTest execution with CLI switching
- Headless mode for fast test runs
- Data-driven testing using CSV, JSON, and Excel
- Faker-based test data for dynamic values
- TestNG + Page Object Model architecture
- Maven CLI execution with runtime parameters
- ExtentReports HTML reporting
- Log4j logging with logs stored in /logs
- Automatic screenshots on failures
## Tech stack
- Java 11
- Selenium WebDriver
- TestNG (test runner & suites)
- Maven (build + dependencies)
- OpenCSV / Gson / Apache POI (data sources)
- Faker (fake test data)
- LambdaTest (remote cloud execution)
- ExtentReports (HTML reports)
- Log4j (logging)
## 🚀 How to Set Up the Framework

**1. Clone the Repository**
```bash
git clone https://github.com/vanajachowdary16/JatinSirAutomationAssignment.git

cd JatinSirAutomationAssignment
```
**2. Install Maven Dependencies**
```bash
mvn clean install
```
**3. Configure LambdaTest (If using cloud)**
```bash
src/main/resources/config.properties
```
